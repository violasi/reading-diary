# 阅读打卡日记 — 孩子端设计

设计日期：2026-07-31｜设备：Android 平板（Capacitor APK）｜**锁定竖屏**

绘本页是竖版（1242×1920，宽高比 0.65），竖屏能让页面占满屏幕、字最大。横屏会浪费两侧、字变小。

## 0. 使用者画像决定的三条铁律

孩子在读 RAZ Level A（英文启动级），**认不了几个字，更认不了中文说明**。所以：

1. **一屏一个主要动作**。次要操作要么藏起来，要么明显小一号
2. **能用图标就不用字**。孩子端全部中文加起来不超过 20 个词，且都是"再听一遍"这种反复出现、
   看两次就记住位置的固定按钮
3. **只有正反馈**。不做扣分、不做失败、不做倒计时、不做"答错重来"。
   低龄孩子的驱动力来自"我又收集到一个"，不是"我别做错"

## 1. 三个兴趣元素的分工

不把三个概念混着堆图标，各给一个明确职责：

| 元素 | 职责 | 为什么是它 |
|---|---|---|
| 🐟 **捞鱼** | 第二关**每页捞一条鱼**进鱼缸 | 捞鱼天生可重复、可计数，一页一条，进度条不用画进度条 |
| 🦋 **抓蝴蝶** | 第一关**听完抓到一只蝴蝶** | 听一遍是一次性动作，配一只飞进来被网住的蝴蝶 |
| ⚡ **奥特曼** | **陪读伙伴**；第三关录音时**充能变身**；**日历上留下当天陪读的是谁** | 变身本就是"攒能量→爆发"，正好对应"完整读一遍" |

**收集节奏**：听完 → 1 只蝴蝶；每页跟读 → 1 条鱼；整篇录完 → 奥特曼充能满一格；
一天全部读完 → 奥特曼变身 + **日历上留下今天这位奥特曼**。

**打卡日历本身就是收集册。** 每天进入时挑一个奥特曼陪读，读完那天就留下它的身影。
孩子回看日历会看到一整墙不同的奥特曼 —— 收集的动力已经在这里了，不需要再额外做一套收集物，
也就少了一层要维护的图片资源和等级规则。

### 素材来源（都不花钱）

- **蝴蝶 / 鱼 / 能量槽**：我们自己画**内联 SVG**。零文件、零版权、离线可用，
  且不同安卓版本渲染一致 —— 用 emoji 会因系统字体不同而长得不一样，别用
- **奥特曼形象**：**直接沿用 `orange_read` 的 9 个角色**，已压缩后放在
  `public/images/ultraman/`：`taro` 泰罗、`zero` 赛罗、`tiga` 迪迦、`belial` 贝利亚、
  `zeta` 泽塔、`father` 奥特之父、`mother` 奥特之母、`orb` 欧布、`ginga` 银河。
  Q 版全身像、**透明背景**，原图 1024×1024 共 13.5 MB，已缩到 256×256 共 608 KB。
  缺图时退化为角色名首字的彩色圆形

## 2. 页面清单：孩子端只有 3 个页面（+1 个家长页）

关键取舍：**三关共用一个"阅读页"壳**，顶部进度条和中间页面图的布局完全不变，
只换底部那条操作栏。孩子学会一次就会全部三关，代码也只需要一个容器组件。

```
① 首页（今日任务）
     ↓ 点一本书
② 阅读页  ── 关1 听 ─→ 关2 跟读 ─→ 关3 录音 ─→ 完成浮层
     ↓ 回到首页（全部读完 → 奥特曼变身 + 日历上留下今天这位）
③ 我的（日历 + 收获 + 星星）        ④ 家长模式（PIN 进入）
```

孩子的主路径是**一条直线**，没有任何岔路：首页 → 点书 → 关1 → 关2 → 关3 → 回首页。
「我的」是可选浏览，「家长模式」孩子进不去。

### ① 首页

- **顶部**：陪读奥特曼（Q 版全身像）+ 名字
  - **当天首次进入时挑一个，挑完即锁定**，当天不能再换 —— 否则日历记录的"那天是谁"就没意义了
  - 第二天进入时重新挑
- **中间**：每本书一张大卡片 —— 封面图 + 书名（英文原名）+ 三个关卡小图标 🦋🐟⚡
  - 未做的关：灰色轮廓；做完的关：点亮上色
  - 整本读完：卡片盖一枚奥特曼印章，不再可点（防止重复刷）
- **底部**：两个入口。「我的」较大，「爸爸妈妈」明显小一号且在角落
- **没有今天的任务时**：奥特曼摊手 +「今天还没有任务哦」，下面是导入提示
  （App 自动扫描下载目录发现 `.rdpkg`，发现了就在这里冒出「有新任务！」大按钮）

### ② 阅读页（三关共用）

固定布局，三关都一样：

```
┌──────────────────────────────┐
│ ←   🦋 ──→ 🐟 ──→ ⚡          │  顶部：三关进度，当前关高亮放大
├──────────────────────────────┤
│                              │
│      绘本整页原图             │  中部：占屏幕约 70%，字就印在图上
│    （字在图上，不另外渲染）    │
│                              │
├──────────────────────────────┤
│      随关卡变化的操作条        │  底部：唯一变化的区域
└──────────────────────────────┘
```

**关 1 · 听一遍**（`listen.mode: "sequence"`）
- 一个**巨大的播放键**，占满操作条
- 播放中：自动逐页翻图，播放键变成声波动画，一只蝴蝶在页面上方飞
- 播完：蝴蝶被网住 → 出现两个键 `[🔁 再听一遍]` `[去跟读 →]`
- **听完就能过**，不出题、不设卡

**关 2 · 逐页领读**
- 操作条：`[▶ 听这页]` + `[我读好了 →]`
- 底部一条**鱼缸**：本书共 N 页 = N 个空位，每点一次「我读好了」游进一条鱼
- 不判分、不录音，孩子自己控制节奏；`[▶]` 可以反复点，想听几遍听几遍

**关 3 · 整篇录音**
- 页面图可左右翻，孩子边翻边读
- 操作条：`[● 开始录音]` → 录音中 `[■ 读完了]`
  - **点一次开始、点一次结束，不用长按** —— 长按对小手不可靠，且录长句必松手
  - 录音中：奥特曼能量槽随音量充能（有声音就在涨），这是给孩子的"麦克风真的在听"的确认
- 录完：`[▶ 听听我读的]` `[🔁 重录]` `[交给爸爸妈妈 ✓]`
- 交完 → 奥特曼变身动画 → 回首页

### ③ 我的

一页到底往下滑，不分 tab（对小孩来说一页滚动比切 tab 简单）：

1. **打卡日历**：读过的每一天，格子里站着**那天陪读的那位奥特曼** —— 这就是收集册
2. **两个数字**：`最长连续 12 天` 和 `总共读了 23 天`。
   **断了不归零** —— 漏一天不清零、不提示、不补救，只是那天日历上空着。
   低龄孩子断更多半不是他的错（出门、生病、大人忘了），归零是在惩罚家长的日程
3. **爸爸妈妈的星星**：每本书一行，书名 + ⭐⭐⭐⭐⭐

### ④ 家长模式

**成人界面，不要卡通**。数字键盘输 PIN 进入。

- **PIN 默认 `123`**，在这里的**设置 → 改 PIN** 里修改。首次使用不需要设置向导，直接就是 `123`
  （这道锁是防孩子误触，不是防破解；哪天孩子会数数、自己按开了，进设置改成长一点的就行）
- **今日录音**：每条 = 书名 + 时长 + `[▶]` + 5 颗星打分（点星即存，不要"提交"按钮）
- **导入任务包**：自动扫描下载目录的结果列在这里，也有手动选文件兜底
- **设置**：孩子名字、改 PIN、导出备份

## 3. 交互细节（都是踩过或预判的坑）

| 细节 | 决定 | 原因 |
|---|---|---|
| 屏幕方向 | **锁竖屏** | 绘本页是竖版，竖屏字最大 |
| 录音触发 | **点击开始/结束**，不长按 | 长按对小手不可靠，且长句必松手 |
| 录音中反馈 | 能量槽随音量涨 | 孩子需要"麦克风真的在听"的确认，否则会一直问大人 |
| 页面图预加载 | 进阅读页时预载全部页图 | 已在 IndexedDB 里，翻页不能有白屏等待 |
| 音频播放 | 首次播放需用户手势触发 | WebView 的 autoplay 限制；关 1 的大播放键天然满足 |
| 完成后防重刷 | 整本完成即锁卡片 | 否则孩子会反复读同一本刷奖励，跳过没读的 |
| 退出保护 | 关 3 录音中按返回要二次确认 | 避免误触丢掉刚录的 |
| 无障碍 | 所有可点区域 ≥ 64×64 dp | 小孩点不准 |
| **页面图容器必须 `min-height:0`** | 阅读页中部那个 `flex:1` 的容器 | ⚠️ 已在设计稿上踩过：flex 子项的自动最小高度由内容决定，整页图撑着不肯缩，溢出被 `overflow:hidden` 剪掉 —— **剪掉的正好是页面底部那行字，而那行字就是孩子要读的内容**。配 `object-fit:contain` |
| 关卡状态样式用显式 class | 别用 `nth-of-type` | ⚠️ 已在设计稿上踩过：返回箭头也是 `span`，把序号顶掉一位，三关颜色整体错位 |

## 4. 视觉基调

- **主色**水蓝（鱼/水），**动作色**橙黄（蝴蝶/能量，所有主按钮），**点睛色**奥特曼红银
- 大圆角卡片、高对比、留白足；不用细字重、不用小字号
- 动画只在**得到东西的那一刻**出现（网住蝴蝶、鱼游进缸、能量满、变身），
  平时页面是安静的 —— 满屏乱动会抢掉孩子对绘本内容的注意力

## 5. 已定的细节汇总

| 项 | 决定 |
|---|---|
| 第一关 | 只完整听一遍（可重听）即可继续，不出题、不设卡 |
| 家长反馈 | 只给 5 颗星，不录语音 |
| 家长 PIN | **默认 `123`**，家长模式 → 设置里改 |
| 连续天数 | **断了不归零**，展示「最长连续」和「总天数」两个数字 |
| 陪读奥特曼 | **当天首次进入时挑，挑完锁定**，第二天重新挑 |
| 收集物 | 只有打卡日历（每天留下当天那位奥特曼），不做额外收集系统 |
| 屏幕方向 | 锁竖屏 |
| 录音触发 | 点击开始 / 点击结束，不长按 |
